# AI Fitness Website

AI Fitness Website is a web application that helps users explore workouts and exercises for different muscle groups. The website provides exercise demonstrations using GIFs and an easy-to-use interface for fitness enthusiasts.

## Features

* Exercise recommendations for different muscle groups
* Animated exercise demonstrations
* User-friendly interface
* Responsive design
* Workout categories including Chest, Back, Biceps, Shoulders, Legs, and more

## Technologies Used

* HTML
* CSS
* JavaScript
